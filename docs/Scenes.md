# ChemVR Scene Guide

Reference for every Unity scene under `Assets/Scenes/`. Generated by inspecting the
scene YAML directly (root hierarchy, prefab instances, `MonoBehaviour` scripts) plus
`ProjectSettings/EditorBuildSettings.asset` and git history.

- **Objects** = plain `GameObject`s serialized in the scene.
- **Prefabs** = `PrefabInstance` entries. Most lab furniture and glassware are prefabs,
  so this is the better indicator of scene "weight".
- **Last touched** = last commit that modified the `.unity` file.

## Scene-to-scene navigation

Runtime scene loads are hard-coded by name in three scripts:

- `Assets/Scripts/StartMenuController.cs` — menu buttons load `LabSceneTutorial`,
  `LabSceneGloveHygiene`, `LabSceneGlasswareUse`, `LabSceneChemicalChange`, `Start Menu`.
- `Assets/Scripts/Menu/HelpMenuController.cs` — same five targets from the in-game help menu.
- `Assets/Scripts/SpawnAtStation.cs` — reloads the current module by name.
- `Assets/Scripts/TutorialSceneController.cs` — loads the **next build index**, so it depends
  on build-settings ordering rather than names.

```
Start Menu ──┬─> LabSceneTutorial ──(next build index)──> LabSceneGloveHygiene
             ├─> LabSceneGloveHygiene
             ├─> LabSceneGlasswareUse
             └─> LabSceneChemicalChange
                        └── all four can return to Start Menu via the help menu
```

The per-developer variants (`_Aayushi`, `_Zack`, `_Woodhouse`, `Woodhouse…`) are **not**
reachable from the menu — they are opened directly in the editor.

## Common scene structure

The newer scenes (glassware VR + all WebGL) share a consistent set of root objects:

| Root | Contents |
|---|---|
| `Environment` | Static lab: office door, over-door wall, `Titration_Holders_Red/Blue/Yellow`, sinks and drying rack, per-module item groups, extra glassware |
| `Player` | `Complete XR Origin Set Up Variant` (VR) or `FP Player` (WebGL first-person rig) |
| `Managers` | Single `The Managers` prefab — task manager, hygiene manager, module overview, spawn logic |
| `Setup` | `Light Probe Group`, `Reflection Probe Group` (4 probes), `ParticleHolder`, `Particle Sphere` |
| `Canvases` | Interact icon, WebGL item canvases (WebGL builds only) |
| `--------------------` | A visual separator object; everything below it is loose prefab clutter (glassware, tables, brushes) that was never re-parented |

The older scenes (`LabSceneTutorial`, `LabSceneGloveHygiene`, `LabSceneBase`) predate this
layout. They use a flat root list with `VR Movement and Interaction` in place of
`Player`/`Setup`, and per-module `… Goals` / `… Items` roots.

Module task definitions live outside the scenes as ScriptableObjects in
`Assets/Resources/Tasks/{Tutorial,Glove_Hygiene,Glassware_Use,Chemical_Change}/`, driven by
`Assets/Scripts/TaskSystem/`. The narrative step lists are in `GloveHygiene_Module.txt` and
`Chemical change.txt` at the repo root.

### LabSceneGloveHygiene

`Assets/Scenes/LabSceneGloveHygiene.unity` — 61 objects, 110 prefabs — last touched 2025-04-10 (Carson Strout)

The glove hygiene / titration module. Step list: `GloveHygiene_Module.txt`. The player dons
PPE, gathers a beaker and two Erlenmeyer flasks, sets up a burette in the red zone, titrates
through scripted interruptions (phone call, coffee break, malfunctioning printer), records
findings with pencil on paper, then removes gloves at the trash. Contamination is tracked and
all spills are revealed at the end.

Roots: `Glove Hygiene Goals`, `Glove Hygiene Items`, `ParticleHolder`,
`VR Movement and Interaction`, plus the shared environment roots.

Key scripts: `HygieneManager` (contamination tracking), `AddGloves` / `RemoveGloves`,
`WearGoggles`, `WearCoat`, `Pencil_To_Paper`, `ScribbleSound`, `DisableHoldable`,
`StartTasks`, `SpawnAtStation`.

### LabSceneGlasswareUse

`Assets/Scenes/LabSceneGlasswareUse.unity` — 104 objects, 145 prefabs — last touched 2026-01-14 (AayushiRajput)

The canonical VR glassware module: identify glassware, inspect it for damage, use it, then
clean it at the sink and put it away.

Roots: `Environment`, `Player`, `Managers`, `Setup`, `Canvases`, `Glassware_Table`,
`ScrubBrush (2)`, `cabinet_3 (5)`, and the `-----` separator.

`Glassware_Table` is the inspection table — `*_inspect` prefab copies of beakers, volumetric
pipettes, flasks, DI water and a stir rod, each labelled with a `Text (TMP)` object.

Key scripts: `ChemContainer` ×3 and `ResizeFluid` ×3 (liquid volume), `SolutionBubbleAudio` ×3,
`GlassClink` ×3, `PickupToggle` ×3, `ScrubWithBrushObj` ×2 (sink cleaning), `DoorOpen` ×2,
`TriggerForBringToHood`, `TriggerForPutAway`, `Report_Grab`, `HygieneManager`,
`AddGloves` / `RemoveGloves` / `WearCoat`, `StartTasks`, `SpawnAtStation`.

### LabSceneChemicalChange

`Assets/Scenes/LabSceneChemicalChange.unity` — 115 objects, 123 prefabs — last touched 2025-07-29 (Roswell_Winters)

Key scripts: `Chemical_Change_Overview`, `Start_Module`, `Table_Contents` ×15,
`SnapBulbToPipetTwo` (pipette bulb assembly), `PourActivator`, `Wobble`, `ResizeFluid`,
`ChemContainer`, `LG_Put_Paper_on_Boat`, `ButtonPressCheck` (balance/hot-plate buttons),
`WearCoat`, `WearGoggles`, `AddGloves`, `RemoveGloves`, `PrinterSlap`, `HygieneManager`,

### LabSceneBase

`Assets/Scenes/LabSceneBase.unity` — 165 objects, 142 prefabs — last touched 2024-12-12 (Skarlet Williams)

## WebGL scenes

WebGL ports replace the XR rig with `FP Player` (first-person WASD/mouse via
`Assets/Scripts/WebGL/FirstPersonMovement.cs`) and add `WebGLInput`, `IconHider`,
`ActiveItemsCanvas`, and `WebGL Item Canvas` UI under `Canvases`.

### WebLabGlassware-Aayushi

`Assets/Scenes/WebGL/WebLabGlassware-Aayushi.unity` — 120 objects, 145 prefabs — last touched 2026-01-29 (AayushiRajput)

**The only scene enabled in build settings** — this is what ships today.

Adds a `Glassware_inspection` root (10 labelled prefabs: two beakers, three volumetric
flasks, two volumetric pipettes, graduated cylinder, stir rod, DI water) and `SnapToTray` ×11,
the highest count of any scene — this is the glassware inspection table work from commits
`6761963b` / `48078d26`.

Key scripts: `SnapToTray` ×11, `ToggleSink` ×3 + `ToggleSinkR`, `WashHandsTrigger`,
`DoorOpen` ×2, `GlassClink` ×2, `ResizeFluid` ×2, `ChemContainer` ×2, `SolutionBubbleAudio` ×2,
`TriggerForBringToHood`, `TriggerForPutAway`, `Glassware_Use_Overview`, `Glove_Hygiene_Overview`,
`Start_Module`, `ActiveItemsCanvas`, `IconHider`, `WebGLInput`, `HygieneManager`,
`StartTasks`, `SpawnAtStation`, PPE scripts.

> The eleven `Text (TMP) (2..11)` labels sit at the scene **root** rather than under
> `Glassware_inspection`. They are the inspection-table labels and are easy to move or
> delete by accident.

## Housekeeping notes

Observations from the scan, offered as cleanup candidates rather than bugs:

1. **Build settings are effectively broken for VR.** Only `WebLabGlassware-Aayushi` is
   enabled, so `LoadScene("LabSceneTutorial")` and friends fail in a build. Re-enable the
   VR module scenes before cutting a VR build.
2. **Two dead build-settings entries** (`LabSceneGlasswareUse_Aayushi_initial`,
   `Zack-GlasswareUse`) point at files that no longer exist.
3. **Eight glassware scenes** (4 VR + 4 WebGL) differ mostly by `SnapToTray` count. Picking
   one canonical scene per platform and deleting the forks would remove ~10 MB of scene YAML
   and a recurring source of merge conflicts.
4. **Naming inconsistencies:** `WebLabGlaswareAlpha` (missing "s"),
   `WoodhouseLabSceneGlassware` (prefix instead of `_Woodhouse` suffix),
   `Tutotial Items` in `LabSceneTutorial`.
5. **Loose root objects.** The `--------------------` separator in the glassware scenes is
   followed by dozens of un-parented prefab instances (tables, flasks, brushes). Parenting
   them under `Environment` would make the hierarchy navigable.
6. **`LabSceneBase` has drifted.** It still uses `ChemXRInput` and the old
   `VR Movement and Interaction` layout, so forking a new module from it produces a scene
   that does not match the current `Player`/`Managers`/`Setup` convention.
